# To add an access point

1. Clone https://github.com/jacebrowning/grwifi
2. Visit [http://geojson.io](http://geojson.io)
3. Click on the "Import" button to upload `map.geojson`
4. Click on the "Draw Point" icon on the toolbar
5. Click on the approximate center of the access point
6. Fill in the empty row with the relevant information
7. Click on the "Export" button to download `map.geojson`
8. Run `make` to format the updated file
9. Commit the updated `map.geojson`
